# Roll the Dice

Jednoduchá Flutter aplikácia na hádzanie kockou.

Po stlačení tlačidla Hodiť kockou sa vygeneruje číslo od 1 do 6 a zobrazí sa príslušný obrázok z assets/images. Stav sa aktualizuje cez StatefulWidget a setState, náhodné číslo cez Random z dart:math.

## Spustenie

```sh
flutter pub get
flutter run
```
